# Dreamscape

在 HTTPS 或 localhost 打开 `index.html`。例如运行 `python -m http.server 8000` 后打开 `http://localhost:8000`。首次开启摄像头时浏览器需要加载 MediaPipe 模型。

## REALiTi 手势演出

1. 用张开的手掌扫过画面。
2. 两手分开摊掌，再分别抬高或压低。
3. 单独伸出食指，做一次短点触。可以换到另一侧继续点。
4. 抬手合拢，在脸侧短闭双眼并轻晃，松开后进入半色调、彩色眼块和白剪影的短闪。
5. 两手拇指、食指合成四角，松开后可再次成框切换纹理。
6. 松开取景框，张掌引入飞鸟；两只手分别带动一群。
7. 在左右脸侧各做短点触，累计四次开启四窗。
8. 合拢双手、闭眼、在脸侧小幅绕圈。四窗保持轮换。
9. 绕圈后单独伸出食指，再依次张掌，放下手清场。

采集空房间背景后可调人物透明度。点击采集后，请移出画面，等待空景就绪再回来。摄像头机位或光线改变后需重新采集。当前录像回放没有独立空景，磨砂局部擦除仍然可用。

## 调试和验证

- 在设置里开启调试，或在地址后加 `?debug` 查看当前阶段、手势候选、锚点、素材加载和分割状态。
- “输入回放”接受本地视频与本页导出的关键点 JSON。已镜像的网页录屏勾选“录像已镜像”。关键点回放使用画布坐标与输入时间，背景为校准网格。
- “自由试演”可以从指定阶段练习，音乐进度独立于手势。
- 运行 `node --test tests/gestures.test.cjs` 检查状态衔接和误触路径。
